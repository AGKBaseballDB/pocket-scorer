# pocket-scorer

スマホで一球ずつ記録するスコアブックと、ログインなしで見られる試合速報のページです。

- `index.html`：アプリ本体
- `config.js`：Firebaseの接続設定（firebaseConfig）
- `firestore.rules`：Firestoreのルール。Firebaseコンソールの「Firestore → ルール」に貼り付けて使います。
- `roster-template.xlsx`：選手マスタのひな形
- `vendor/xlsx.full.min.js`：Excelを読むための部品（SheetJS、Apache-2.0）
- `robots.txt`：検索エンジンに載らないようにする設定

## 使い方

- **見る人**：ページのURL（または速報リンク）を開くだけです。ログインは不要で、入力はできません。
- **記録係**：試合一覧の下にある「ログイン」から、Firebaseの Authentication に登録したメールアドレスとパスワードで入ります。
- **選手マスタ**：選手は学年ごとに分けて表示されます。学年は入学年度として記録しているので、毎年4月に自動で1つ上がり、最上級生は「卒業生」に移ります。学年ごとの「この学年をまとめて削除」で一度に消せます。消しても、これまでの試合の記録は残ります。
- **Excelで選手を登録**：`roster-template.xlsx`（選手マスタのひな形）に入力して、選手マスタの「Excel・CSVから登録」で読み込みます。パソコンではファイルを画面にドラッグしても読み込めます。同じ氏名の選手は上書きされます。見出し（背番号・氏名・学年・守備位置・投・打）のあるCSVも読み込めます。
- **パソコンに保存**：パソコンのChromeかEdgeでページを開き、「保存先のフォルダを選ぶ」を押します。保存されるものは次のとおりです。
  - 選んだフォルダの中に、試合ごとの `日付_開始時刻_先攻vs後攻_一球データ.csv`・`…_打撃成績.csv`・`…_投手成績.csv`
  - `選手マスタ.csv`（記録係でログインしているときだけ）
  - 記録が更新されるたびに上書きされます。保存はページを開いている間だけ続きます。
- **元に戻す**：「全試合を1ファイルでダウンロード」で保存したJSONファイルは、「ファイルから試合を戻す」で読み込めます。

## データの置き場所

- 試合のデータはFirestoreの `games` に入ります。このページのURLを知っている人は、すべての試合を見られます。
- 選手マスタ（`team`）と削除の記録（`deleted`）は、記録係しか読み書きできません。
- 記録係の端末にも控えが残るので、電波がない間も入力でき、つながったときに送信されます。
